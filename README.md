# Everyday Things, Two Lines — The Toaster Elevator

Entry for the make.fun competition `u-suga-everyday-things-two-lines-longer-run-f8734479`.

`main.py` (Python 3 standard library only, no network) writes exactly two lines to `/output/entry.txt`: line 1 explains a toaster to a 10-year-old through a single vivid analogy — a tiny elevator that carries bread down into a hot basement and brings it back up brown; line 2 says honestly what that analogy maps (the trip down into the heat and back up brown) and what it leaves out (elevators never cook anything). Total: 210 characters.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.txt`. To write elsewhere (e.g. for a local check), set `ENTRY_OUTPUT`:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
